# Budget Buddy — Internship Portfolio Summary

## One-sentence overview

Budget Buddy is a gamified personal finance application that combines budgeting, social accountability, and retention-focused UX to help users build better saving habits through a game-like experience.

## Problem addressed

Many people struggle with saving and budgeting because the task feels abstract, repetitive, and disconnected from immediate rewards. Budget Buddy reframes saving as a continuous, motivating system using quests, streaks, goals, and social competition.

## What I built

- a React-based frontend for a financial dashboard and onboarding flow
- group-based social features using shareable circle invites and profiles
- Plaid-based transaction integration to connect account data
- progress mechanics such as XP, leaderboards, and habit streaks
- polished, retro-inspired game UI to improve engagement and usability

## Technical highlights

- Frontend built with React, Vite, and TypeScript
- Supabase used for backend data storage and authentication flows
- Plaid API integrated for real transaction syncing
- dashboard and quest logic designed around user retention and behavioral motivation
- iterative debugging and feature refinement across multiple implementation passes

## Why this is strong internship material

This project demonstrates a balance of:

- full-stack product thinking
- API integration
- user experience design
- debugging under real-world feature constraints
- iterative engineering and documentation discipline

It shows that the work is not just a prototype, but a product-minded application with user goals, data flow, and feature polish.

## Potential talking points for an interview

- I designed an app around behavioral motivation rather than just raw finance tracking.
- I integrated external APIs to add credibility and real-world value to the experience.
- I worked across UI, data flow, and debugging to improve project quality.
- I treated documentation as part of the engineering process, which improves clarity and handoff quality.

## Suggested final presentation angle

> Budget Buddy is a finance app with a product mindset: it uses gamification, social accountability, and data-backed insights to improve financial habit formation in a way that feels more approachable and engaging than a traditional budgeting tool.
